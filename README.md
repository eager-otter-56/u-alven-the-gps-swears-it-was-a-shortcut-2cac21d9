# In the Correct Order

The GPS's one-line excuse for sending the driver down the wrong road: the map said the lake was a road, the road was a driveway, and the driveway was a wedding — so it took the driver to all three, in the correct order. Smug, defensive, and blaming the map, exactly as a caught-red-handed GPS would.
